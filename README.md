# ⚡ JRG Agency — Leads CRM & Commercial Pipeline

Sistema integral de gestión de prospección comercial, calificación de clientes y cierre de ventas para **JRG Agency**.

---

## 🚀 Estructura del Repositorio

* **`01_🖥️_App_CRM_Comercial/`**: Aplicación web interactiva (Pipeline visual estilo Kanban, autenticación comercial, generador de pitch con IA, botón directo a WhatsApp y llamadas).
* **`02_📊_Bases_Datos_Leads/`**: Bases de datos maestras (`leads_master_total.json` y `leads_master_total.csv`) con más de 2.400 comercios calificados de Goierri y Alto Urola.
* **`03_📚_Documentos_PDF_y_Guias/`**: Guías de prospección y documentación comercial.
* **`04_⚙️_Scripts_Scraping_y_OCR/`**: Herramientas y utilidades de extracción.
* **`05_💾_Copias_de_Seguridad/`**: Historial de versiones y copias de seguridad de datos.

---

## 🛠️ Ejecución Local

Para abrir el panel interactivo en local, ejecuta el lanzador:
```cmd
abrir_crm.bat
```
